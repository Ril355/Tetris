# Tetris

`pygame` で動くシンプルなテトリスです。

- 落下するミノを左右移動・回転できます
- 横一列が埋まるとライン消去されます
- `Next+1` / `Next+2` で「次」「次の次」のミノを表示します
- スコア計算・ホールド機能は実装していません

## 起動方法

1. `pygame` をインストール  
   `pip install pygame`
2. 実行  
   `python main.py`

## 操作

- `← / →`: 左右移動
- `↓`: ソフトドロップ
- `Space`: ハードドロップ
- `↑` または `X`: 右回転
- `Z`: 左回転
- `R`: ゲームオーバー後にリスタート
- `Esc`: 終了
